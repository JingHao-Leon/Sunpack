# GUI 测试取舍

所有测试使用隔离文件，不控制正式 Watch、自启或密码文件。没有性能阈值测试。

| 测试 | 独立发现的功能故障 | 删除后的缺口 | 成本与价值 |
|---|---|---|---|
| `manager.cpp` 原生文件契约 | 日志状态转换、部分末行、同文件截断重长；密码作用域删除/严格校验；未知配置与大整数保真；重叠目录、500 项分页；CLI 参数转义与退出码 | 界面测试只覆盖一条任务和小文件，无法发现这些边界语义错误 | 约 0.1 秒，一次覆盖文件契约，无逐字段细粒度测试 |
| `interface.cpp` 原生界面集成 | 真实控件事件到工作线程和文件回读；主题下拉框切换；字段列表进入/返回；850×560 窗口下配置和密码保存；中文输入；CLI 子进程；外部原子替换、无效配置恢复、日志目录重绑定及退出；可选截图 | 纯数据测试无法发现不可点击按钮、失效绑定、被裁剪的保存操作或观察器生命周期故障 | 通常不到 1 秒；复用同一窗口，使用有截止时间的消息等待，无固定等待规避竞态 |
| Python Mutex 一致性 | C++ 与真实 Python/Rust 的 Unicode、UNC、分隔符和目录根锁名一致 | C++ 自检无法证明跨语言互斥 | 数次短进程启动，阻止密码/目录并发写入失锁 |
| Python 剪贴板协作 | 实际 Python 剪贴板写入与原生 GUI 密码保存共享锁并保留最新历史 | 锁名相等和单语言模拟不足以证明实际写入链路兼容 | 一个子进程，无睡眠；覆盖唯一跨语言写入路径 |
| Python 安装版启动 | 托盘定位独立管理器、复用降权启动并释放原生子进程句柄 | 托盘测试仅替换启动函数，无法发现实际路径和生命周期错误 | 纯单元测试，几毫秒 |

`tests/unit/test_windows_tray.py` 原有文件打开测试被菜单/左键统一打开管理面板
的测试替代，旧实现与对应旧断言一并删除。
